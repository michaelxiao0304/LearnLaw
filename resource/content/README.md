# 正式内容工作区

当前没有正式内容、官方快照或真实审核记录；这是明确的发布阻塞项。

- `schema/bundle.schema.json`：工具生成的结构契约。
- `v1-requirements.json`：PRD 首版必须覆盖的主题，不能通过删除标记绕过。
- `reviewers.json`：实际审核人员登记，当前为空。
- `source/`：官方原始文件与来源快照，待提供。
- `releases/`：经过专业审核的版本化内容包，待提供。

完整录入、审核、编译和测试步骤见 [内容工具说明](../../tools/content/README.md)。测试工具的合成样例不属于此目录的正式内容。
