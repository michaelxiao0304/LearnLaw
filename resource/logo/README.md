# 识法 LawSense — 品牌标识

> 看得懂的法律常识 · 品牌标识规范 v1.0（2026-10-31）

## 一、名称

| | 内容 |
|---|---|
| 中文名 | **识法** |
| 英文名 | **LawSense** |
| App Store 副标题 | 看得懂的法律常识 |
| Bundle ID（暂定） | `com.lawsense.app` |
| 备选名 | 法知了 / 拾法；英文备选 LawSeed |

**释义**

- **识法**：「识」兼指*认识*法律与*识别*违法边界，正好对应产品两件事——学法、查边界；谐音「拾法」，日拱一卒、点滴积累，呼应每日一题的节奏。两字皆为常用字，无生僻字、无歧义，中老年用户也能读对。
- **LawSense**：`Sense` 双关 *common sense*（常识）与 *判断力/感知*——对法律有 sense。与中文名互为镜像：识 = sense，法 = law。
- **合规**：均不含「中国 / 国家 / 全国」「律师 / 咨询」等字样。正式注册前须完成商标第 9、41、45 类检索。

## 二、标志构成

一个图形同时说清三件事，全部由几何构成，无渐变、无描边、无阴影：

```
        ╱╲  ╱╲          ← 两片嫩芽：学法成长
         ╲  ╱
          │             ← 芽茎向下延伸，成为书脊
      ┌───┴───┐
      │       │         ← 一页翻开的书：法条与知识
      └───┬───┘
```

- **书**：左右两页向书脊收拢，形成「翻开」的透视；两页之间留出书脊凹槽，既分割又连接。
- **芽**：从书脊正中长出，与书脊共用同一条中轴线——「法条里长出常识」。
- **刻意规避**：法槌、天平、盾牌、獬豸等老套法律符号（PRD 3.8 明确要求去说教感），改用植物线条表达「生长、可亲近」。

## 三、色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 竹青绿 | `#3A9D6E` | 主色。图标底色、标志主体、强调文字 |
| 暖米白 | `#FBFBF7` | 浅色底。浅色图标、页面底色 |
| 墨色 | `#1F2937` | 中文名、法条正文等需严肃权威的内容 |
| 深色底 | `#101613` | Dark Mode 图标底 |
| 薄荷绿 | `#5EC89A` | Dark Mode 下的标志色（提亮以保对比度） |

绿色刻意压低了饱和度——法律内容需要「可信」而非「活泼」，高饱和会削弱权威感。

## 五、使用规则

**安全边距**：标志四周留白 ≥ 芽尖到书底高度的 1/4。图标内已内置此边距，不要自行放大贴边。

**最小尺寸**
- 图标：≥ 40×40 px。60 px 下已验过，书的轮廓与双叶仍可辨。
- 纯标志：≥ 24 px 高。
- 横版锁版：≥ 200 px 宽，小于此尺寸请改用纯标志。

**禁止**
- ❌ 改色（除本文件列出的两套配色）
- ❌ 拉伸变形、加描边、加阴影、加渐变
- ❌ 旋转、倾斜、加外框
- ❌ 在花纹复杂的照片上直接压反白标志（需加半透明遮罩）
- ❌ 把书与芽拆开单独使用

## 六、iOS 图标规格说明

- 尺寸 1024×1024，**无 alpha 通道**，**不预置圆角**（系统自动裁切）
- 源文件为 SVG，几何全部矢量；改色只需替换 `fill`
- Dark Mode 变体对应 iOS 18 的 dark icon；如需 tinted 变体，用 `mark.svg` 单色版即可
- 中文名文字为**活字**（PingFang SC Semibold），交付 PNG 已烘焙；若在无该字体的机器上编辑 SVG，需安装思源黑体或苹方
