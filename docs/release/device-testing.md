# 真机测试与发布门禁

## 接入真机

1. 在最新迭代 worktree 打开 `ios/LawSense.xcodeproj`，选择 `LawSenseDevelopment` scheme 和连接的 iPhone。
2. 在 Signing & Capabilities 中选择自己的 Team，按设备要求启用 Developer Mode。Team 不写入共享生成器；重新生成工程后需要重新选择，或使用命令行 `DEVELOPMENT_TEAM=实际团队ID` 覆盖。
3. 开发版名称为“识法·开发”，Bundle ID 独立于正式版。所有开发样例明确标注“非法律内容”；不得用于学习真实法律或提交 App Store。
4. 不传 `--ui-testing` 启动真机测试，该参数使用内存库并重置隔离偏好，仅限自动 UI 测试。普通启动可验证杀进程/重启后的本地数据。

## 真机记录（待执行，不能用模拟器代替）

- 设备型号、iOS 版本、构建 commit、剩余空间；首装与已有数据两种状态。
- 飞行模式阅读→引用→答题→错题复习→收藏→杀进程重开；无网络流量观察。
- 修改系统时间、跨日及时区；错题顺序正确，不重复打卡。
- 大字号、VoiceOver、横屏/iPad 分屏、深色、减少动态效果；正文不截断、焦点及控制可操作。
- 设备已有/没有中文系统语音、耳机断开、来电/音频中断、离开页面，确认朗读停止和错误提示。
- 通知拒绝/撤回、提醒时间变更与点击入口；系统分享取消/发送、无邮件客户端的回退（功能接入后执行）。
- 数据删除的确认、取消、重启后结果；存储故障只读降级及原库保留。

## 正式发布仍需

- D01 内容契约与发布工具、D02 三法全文核验、D03/D09 专业签审及 100 卡/300 题；发布加载与内容升级链路验收。
- 已配置真实支持邮箱、隐私政策 URL、个人发布主体及商标/资源授权确认；App Store Connect 隐私问卷与实际应用一致。
- iOS 17 与最低支持档真机兼容性；正式全量内容、Release 冷启动至少 20 次 P95 ≤2s，检索至少 100 组 P95 ≤200ms（150ms debounce 单列），正式内容 ≤15MB。
- 签名 Archive、隐私报告、设备适配下载/安装大小（目标 ≤30MB）、TestFlight 验收及审核资料。

正式 Release 门禁必须等上述内容集成完成后替换为自动校验，不能仅删除门禁脚本绕过。
