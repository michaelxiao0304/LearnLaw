# D04 · iOS 可运行开发版

基线：`057e239`；分支 `codex/ios-app`。按开发 spec 的 D04 先实现可运行纵向流程，并实现该流程所需的 D05 收藏/答题存储和 D08 系统朗读基础。

验收：独立 Xcode 工程（iOS 17+）、共享 logo 转换/打包、免责门禁、五个 Tab、主题浏览、卡片→原文→测验、关键词/条号检索、今日题、收藏/错题/学习记录持久化、字号与朗读设置。独立开发 target 使用显著标注的合成阅读说明样例，不含未经审核的法律事实；正式 target 不携带样例，Release 阶段阻断未接入正式内容包的发版。

本需求不宣称完成 D01/D02/D09 的正式 schema、全量法库或人工审核，不宣称满足正式全量索引性能、课程/称号、提醒、分享图或内容升级映射等后续验收。功能缺口必须在交付记录列出，界面不得把尚未实现的功能表现为可用。

验证：Swift Testing 测试内容边界和确定性规则；Xcode 中测试 SwiftData 持久化；XCUITest 验证首启和收藏/答题链路；模拟器构建启动与截图检查。没有 iOS 17 runtime 和真机时明确记录限制。
