# D07 学习路径、会话与每日队列

分支 `codex/ios-learning-flow`，基线 `471da49`，独立 worktree 开发。采用 ub-mode、SwiftData、Swift Testing 和 SwiftUI 模式。代码目标为原生 iOS 17+。

- 增加四档称号、先修关卡和 80% 通关规则。课程验证拒绝缺题、重复题、循环先修和缺少阶段；正式课程默认至少 10 题。仅开发编译目标生成每关 2 题的合成阅读演示，标记清楚，不冒充正式课程。
- V3 schema 复用 V2 既有模型并新增会话和通关记录，迁移链保留 V1→V2→V3。选项、题目版本、当前题、提交 ID 持久化；退出恢复同一会话，重复推进返回已保存位置。提交和推进分开，重启后可由稳定提交 ID 恢复，不重复计分。题目版本变化时要求明确重新开始，旧答题记录保留。
- 启动/进入前台/跨日/时区变更补齐未来 30 个公历日题目，单次事务写入，幂等重跑。内容变更时重分配未作答的失效题；已作答的旧版本保留历史并提示更新，不静默伪装成当前答案。
- 设置可停止新增学习日期与连续天数，保留错题、答题及关卡功能必需记录；清除学习记录也清除课程会话/通关，收藏独立保留。隐私说明同步。
- 答题 ID 快照使用字典，避免重复提交检查和关卡计分反复扫描所有答案。

验证：课程无效结构和称号测试先以未实现行为失败，修复后 15 项领域测试通过；18 项 hosted 测试通过，包括 V1/V2 文件库升级、关卡选择恢复、先修限制、重复推进、日期开关及 30 日队列；新增 UI 流程实际通过“选择→退出→恢复选项→两题提交→通关→解锁下一档”。结果包 `learning-tests.xcresult`。

仍需真实审核课程和题库接入；当前演示不能证明正式内容规模性能。学习会话可恢复不等于系统备份、真机低存储和所有迁移中断情形已验收。
