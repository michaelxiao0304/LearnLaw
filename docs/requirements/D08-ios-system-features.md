# D08 系统能力迭代

独立 worktree：`.worktrees/ios-system-features`；分支 `codex/ios-system-features`，基于 `590737f`。使用 ub-mode、push-notifications、SwiftUI/Swift Testing skill；Apple UserNotifications、ImageRenderer、ShareLink 文档用于 API 核查。

## 实现

- 提醒默认关闭，仅主动开启请求权限；单个固定 ID 的本地每日重复通知，无 APNs 注册、无服务器。拒绝/撤回显示系统设置入口；开启、修改、关闭经串行任务提交，避免旧调度在关闭后残留。进入前台重新核对授权。
- 通知点击只表达“打开今天的题”，不缓存法律结论；经过首启声明及内容加载门禁后展示今日题。TTS 保持既有离线/中断行为。
- 原文分享使用 ImageRenderer 逐页生成 PNG，保留全部字符及 Unicode 字素簇；每页显示品牌、版本、来源、页码和免责声明，开发版带非法律原文标记。按字符数和换行数分页，无固定高度裁切；超过 100 页明确提示使用完整文本复制，不静默截断。使用 ShareLink，无相册权限。成功文件留在应用临时目录交由系统清理，失败/取消生成删除本次临时目录。
- 纠错页生成内容精确 ID、内容包、App 版本与用户说明的可预览草稿；只在主动点击时打开 mailto，不自动发送、不附带学习记录。邮箱为空时没有发送按钮，保留复制草稿；无邮件客户端显示复制回退。
- `ReleaseConfiguration.swift` 预留真实邮箱和 HTTPS 隐私政策网址，当前空值。Team 由用户在 Xcode 选择。隐私说明同步新增本地提醒设置和临时分享文件行为。

## 验证

分页/纠错测试先以未实现行为执行，4 处断言失败，再实现后 13 项领域测试通过。通知测试覆盖默认不开启权限、拒绝/撤回、修改时间、取消及调度失败恢复。UI 验证图片生成和未配置邮箱流程；最终结果在收尾时补记。

通知实际到达、锁屏/专注模式、点击冷启动、系统分享接收端、真实邮件客户端及飞行模式朗读仍需真机验收，不能用模拟器适配器测试替代。正式数据与签审门禁保留。

最终验证：13 项领域测试通过；原有 10 项数据测试及初始 2 项提醒测试通过；补充快速关闭竞争测试先复现“关闭后仍弹授权”失败，修复过期请求后 4 项提醒测试全部通过。分享/未配置纠错 UI 流程实际执行并通过（`system-final.xcresult`）；已查看真实生成的 PNG，品牌、完整样例原文、来源、版本与免责声明均完整可读。分享页提供逐页预览。真机系统通知和外部接收端验收仍待执行。
