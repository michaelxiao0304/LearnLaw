# 普法工具 App 产品需求文档（PRD）

| 项目 | 内容 |
|---|---|
| 产品名称 | 「识法」LawSense——看得懂的法律常识（iOS 优先） |
| 文档版本 | v1.2（2026-10-27 最终定名「识法」/ LawSense，四项决策见第 8 章） |
| 产品形态 | 工具型 App：**内置内容、无 UGC、无社区、离线优先** |
| 明确不做 | 法律咨询、律师对接、代写文书、有偿法律服务 |
| 首要原则 | **内容准确性 > 一切**；生动易懂服务于准确性，不凌驾于准确性 |

## 1. 产品定位

### 1.1 一句话定位

一款面向中国普通大众的**法律常识学习与查询工具**，把刑法、民法典、治安管理处罚法（"三法"）中与日常生活最相关的知识，用"看得懂的法条 + 场景化案例 + 轻量测验"的方式系统化普及，帮助普通人建立基础法律意识：**知道哪些行为违法、后果是什么、遇到事情大概该怎么办**。

### 1.2 目标用户

- 完全没有法律背景的成年人（学生、上班族、个体户、老人等）
- 核心诉求：不是"学法条"，而是"我想知道我的事怎么算"
- 典型场景：刷到新闻想知道"这算什么罪"；自己遇到纠纷想知道"这违法吗、该咋办"；家长想给孩子做防犯罪教育

### 1.3 产品边界（红线）

**做：** 普法教育、法条查询、案例科普、知识测验、概念解释。

**不做（合规红线）：**
- ❌ 任何形式的法律咨询（包括"帮我看下这个判决/合同"）
- ❌ 律师/法务对接、付费咨询入口
- ❌ 用户间社区、评论、UGC、问答
- ❌ 代写文书、案件评估、胜诉预测
- ❌ 对具体个案给出"你应该怎么做"的结论性建议

所有内容页脚固定免责声明：**"本 App 内容仅为法律知识普及，不构成法律意见。具体法律问题请咨询执业律师或前往法律援助机构（12348 热线）。"**

### 1.4 与竞品的差异

| 竞品类型 | 代表 | 我们的差异 |
|---|---|---|
| 官方资讯门户 | 司法部智慧普法平台 | 我们做系统化学习路径，不做新闻橱窗 |
| 考核任务型 | 法宣在线、青少年普法网 | 我们是"我想知道"驱动，非摊派考核 |
| 法条检索 | 各类法规汇编 App | 我们查得到更看得懂：每条法条配白话解读与生活场景 |
| AI 咨询 | 法行宝等 | 我们不靠 AI 回答（规避幻觉风险），做**确定性内容库**：答案固定、可溯源、离线可查 |
| 短视频普法 | 罗翔说刑法等 | 我们把"看热闹"变成"会判断"：测验巩固 + 可查证法条 |

**核心差异化：** 法条原文层 100% 来自官方渠道且锁定现行版本；解读层人工编纂、白话化；案例层改编自公开权威来源。答案确定、有据可查、无需联网——这是 AI 问答类产品做不到的。

### 1.5 产品命名（已定）

**中文名：识法**。取"认识法律、识别违法边界"之意，与成语"识法者、逐法而行"的语感暗合；谐音"拾法"——日日拾法，点滴积累。一词双关，直白传达产品价值：帮你认识法律。

**英文名：LawSense**。"Sense"兼指"认知/常识"（common sense 的 sense）与"感知/判断力"——对法律有 sense，正是"识法"的英文镜像表达；词形简洁、发音易读，适配国际化展示与 App Store 命名。

- **易读易记**：中文两个常用字，无生僻字、无歧义，中老年用户也能正确读出；英文 LawSense 拼读直观
- **合规性**：不含"中国 / 国家 / 全国""律师 / 咨询"等敏感字样；初步重名核查未发现法律类同名产品（LawSense 在 App Store 中国区未见同名应用；正式注册前须完成商标第 9、41、45 类检索）
- **备选名**（商标冲突时启用）：法知了（谐音"知法了"）、拾法（谐音"识法"，日拱一卒）
- **App Store 命名**：识法（副标题：看得懂的法律常识）
- **Bundle ID（暂定）**：`com.lawsense.app`，定稿前查重

## 2. 数据源与准确性保障（最高优先级章节）

### 2.1 官方数据源清单

所有法条原文、法律事实、数据**只允许来自以下来源**，禁止使用自媒体、百科、第三方 App 转载内容作为事实依据：

| 优先级 | 来源 | 用途 | 说明 |
|---|---|---|---|
| P0 | **国家法律法规数据库**（flk.npc.gov.cn，全国人大常委会办公厅主办） | 三法条文原文、立法沿革、时效状态 | 法条文本唯一权威来源，逐字校对 |
| P0 | 中国人大网（npc.gov.cn） | 法律修订公告、条文释义、立法说明 | 跟踪修订动态 |
| P1 | 中国政府网（gov.cn） | 国务院发布的相关行政法规、公报 | 补充行政类规定 |
| P1 | 最高人民法院官网 / 人民法院案例库、指导性案例 | 案例、司法解释要点 | 案例改编来源 |
| P1 | 最高人民检察院官网（spp.gov.cn） | 检察环节普法、典型案例 | 案例补充来源 |
| P1 | 公安部官网及地方公安政务号 | 治安类典型案例、执法权威解释 | 治安管理处罚法配套解读 |
| P2 | 司法部智慧普法平台（legalinfo.moj.gov.cn）、"中国普法"微信公众号 | 官方普法素材、宣传口径 | 参考官方表达方式，不直接搬运需核实 |

### 2.2 三法基线版本（截至 2026-10，全部须以国家法律法规数据库"现行有效"版本核对）

| 法律 | 现行版本要点 |
|---|---|
| 《刑法》 | 现行有效版本含刑法修正案（十二）（2024-03-01 施行）；以国家法律法规数据库标注版本为准 |
| 《民法典》 | 2021-01-01 施行；相关司法解释持续更新，司法解释仅引用要点不全文收录 |
| 《治安管理处罚法》 | **2025-06-27 十四届全国人大常委会第十六次会议修订通过，2026-01-01 施行**；多数老 App 仍是 2012 版旧法条——这是内容时效性差异化的关键点 |

### 2.3 内容三层架构（准确性的产品化保证）

```
┌─ 案例层（可更新）────  社会生活场景卡、改编案例、测验题
├─ 解读层（可更新）────  白话解读、常见误区、行为后果速查 —— 人工编纂 + 双人审核
└─ 法条层（版本化）────  官方原文，逐字校对，禁止改动 —— 唯一权威事实层
```

- **法条层不可变**：以"法律名 + 版本日期"为版本号整体打包（如 `zaf_20260101`），App 内展示法条时必须显示版本状态（"2026-01-01 施行版本"）。
- **解读层逐条挂接法条层**：每条白话解读、每张案例卡、每道测验题，**必须引用至少一个法条条号**，用户点击条号可直接跳转法条原文。无引用的内容不允许发布。
- **案例层只做改编**：来自官方发布的典型案例/指导性案例，改写为生活化叙事，须保留"来源：XX 发布的 XX 案例"标注，不虚构裁判结果。

### 2.4 内容更新机制

1. **法条修订监控**：全国人大常委会会议节点（一般每 2 个月一次）后一周内，人工核查国家法律法规数据库三法页面是否有修订；有修订则触发内容库升版流程。
2. **内容包机制**：内容以 JSON 数据包形式内置 + 随 App 版本更新；重大修订（如司法解释变化影响解读）可走 App 发版更新，不做服务端动态下发（保持工具型、离线优先，规避"互联网信息服务"资质复杂度）。
3. **审核流程**：法条录入双人逐字校对 → 解读/案例由"法学科班审核员 + 执业律师抽检"双签 → 发版前全量回归比对（脚本校验所有引用条号存在于法条层）。
4. **纠错通道**：App 内"内容纠错"入口（邮件形式，单向），标注所涉内容 ID；核实后下个版本修正。
5. **时效标注**：每条法条、每个解读卡必须带"更新至 YYYY-MM"标记，超过 6 个月未复核的内容在内容管理侧告警。

### 2.5 准确性红线（内容生产规范）

- 解读只能做"转译"（把法条语言翻译成大白话），**不得扩展法条未规定的结论**；拿不准就不写，宁可留白。
- 涉及"量刑幅度、处罚种类和幅度"必须原样引用法条表述，不得"约化"成模糊说法（如"可能判几年"须给法条原文区间并注明"具体由司法机关依法认定"）。
- 严禁出现"肯定能赢""这样必判"等结论性表述；对"罪与非罪、违法与合法"边界场景，必须写明"具体情形需结合事实由执法/司法机关认定"。

## 3. 生动易懂的内容设计规范

面向普通人，在保证准确的前提下最大化降低理解门槛：

1. **场景先行**：知识单元以生活场景命名（"捡到手机不还，违法吗？"），而非章节命名（"第五章 侵犯财产罪"）。每单元结构：一句话结论 → 3 分钟场景故事 → 白话拆解（法条原文折叠展示）→ 一个小测验。
2. **一句话结论**：每张知识卡顶部给"结论卡"（如"违法。可能构成侵占，视金额与情节"），先给答案再讲道理，符合大众阅读习惯。
3. **白话转译规范**：法学术语首次出现必须给"人话注释"（如"缓刑=判了刑但暂时不用坐牢，考验期内没出事就不用坐"）；禁止连续使用两个以上未解释术语。
4. **后果可视化**：处罚后果用"速查卡"呈现（拘留天数、罚款幅度、量刑档位），样式统一、引用法条原文。
5. **测验游戏化但内容严肃**：答题闯关（青铜/白银/…称号），题目全部源自知识卡内容，不搞脑筋急转弯；答错自动展示对应法条原文。
6. **每日一题 + 分享卡**：每天一道题（本地通知，不联网）；生成"法律冷知识"分享图（App 名 + 法条原文 + 官方来源标注），微信传播。
7. **无障碍与适老**：支持大字号；关键内容语音朗读（系统 TTS 朗读法条原文与解读，服务老年人）。

### 3.8 视觉与品牌基调（清新自然、便于阅读）

**参考对象**（取其气质，不抄具体元素）：
- **潮汐**：清新自然的配色、留白与呼吸感
- **微信读书**：正文排版舒适度与阅读氛围营造
- **多邻国**：闯关/连胜的游戏化节奏（只取节奏与反馈感，不取高饱和配色）

**设计基调**：
- **色彩**：主色竹青绿 #3A9D6E（自然、中性、不喧闹）；底色暖米白纸感 #FBFBF7；法条层用墨色 #1F2937 以示严肃权威；结论徽章三色（违法-暖橙 / 可能违法-赭黄 / 注意-青绿）；Dark Mode 跟随系统
- **字体与排版**：系统默认字体 + Dynamic Type 动态字体；正文 ≥ 17pt、行距 1.6；法条原文页单独加大一档并保留可复制性
- **版式**：大圆角卡片（16–20pt）、每屏聚焦一个主题、留白充足；插画采用手绘植物/嫩芽线条元素，规避法槌、天平等老套符号的"说教感"
- **图标方向**：绿底或白底 + 一株嫩芽破土 + 一页翻开的书，扁平简约，小尺寸下轮廓清晰

## 4. 功能需求

### 4.1 功能总览

```
首页（今日一题 + 推荐场景卡）
├─ 学法堂（核心）
│   ├─ 场景目录：按生活主题浏览（见 4.3）
│   ├─ 学习路径：闯关式课程（青铜→白银→黄金→王者，共 4 级）
│   └─ 知识卡详情页：结论→故事→拆解→法条原文→小测验
├─ 查法条（核心）
│   ├─ 三法全文检索（条号直达 / 关键词 / 拼音联想）
│   ├─ 法条详情：官方原文 + 白话解读 + 关联案例卡
│   └─ 版本状态展示（施行日期）
├─ 练习场
│   ├─ 每日一题（本地通知）
│   ├─ 闯关答题 + 称号系统
│   └─ 错题本（错题自动关联知识卡复习）
├─ 我的
│   ├─ 学习记录 / 连续打卡 / 称号
│   ├─ 收藏（法条 / 知识卡）
│   ├─ 分享卡片生成
│   └─ 设置：字号、语音朗读、每日提醒、免责声明、内容纠错
```

### 4.2 MVP 范围（V1.0，iOS 单端）

| 模块 | MVP 要求 | 说明 |
|---|---|---|
| 法条库 | 三法现行版全文内置，检索 + 条号跳转 | 数据层：版本化 JSON，含施行日期 |
| 知识卡 | ≥ 100 张（刑法 40 / 民法 45 / 治安处罚 15），每张必含法条引用 | 内容生产是 MVP 最大工作量；刑法+民法典为主打，治安法为补充 |
| 场景目录 | 按 4.3 主题树组织，支持浏览 | |
| 每日一题 | 从题库抽取 + 本地通知 | 题库 ≥ 300 题，均挂知识卡 |
| 测验闯关 | 分级关卡制 + 称号 | 答案解析 = 知识卡 |
| 错题本 | 自动收录 + 一键复习 | |
| 收藏 | 法条与知识卡双收藏 | |
| 语音朗读 | 法条原文与知识卡一键朗读（AVSpeechSynthesizer 系统 TTS），语速可调 | 适老化需求，已确认纳入 V1.0 |
| 免责与纠错 | 全局免责声明页 + 每卡页脚 + 纠错入口 | 合规硬性要求 |
| 无账号 | 完全无注册、无登录、无上报 | 工具型定位，隐私友好，简化资质 |

**V1.0 明确不做**：视频课程、AI 问答、订阅付费、社交分享好友排行、多端同步（数据仅本地，iCloud 备份走系统能力可后置）。

### 4.3 场景主题树（内容骨架，V1.0 覆盖 ★ 项）

**首批内容权重（已定）**：刑法篇、民法篇为**主题篇**，全量覆盖；治安管理处罚法篇为**补充篇**，首批约 15 张卡，聚焦 ★ 场景与 2026 新法亮点，其余主题留待后续版本扩充。

**刑法篇（离普通人的罪与罚有多远）**
- ★ 钱财：捡到不还、捡了就花、偷与抢的边界
- ★ 网络与现实暴力：打架斗殴、寻衅滋事、帮人"撑场子"
- ★ 黄赌毒：赌博、代购毒品、"跑分"帮信罪
- ★ 网络犯罪：电信诈骗、帮信罪、传播谣言
- 性与家庭：强奸/猥亵的边界、传播淫秽物品
- ★ 醉驾酒驾：酒驾入刑、隔夜酒
- 未成年人：刑事责任年龄、校园欺凌

**民法篇（过日子的规则）**
- ★ 借钱：借条怎么写才有效、利息红线、诉讼时效
- ★ 租房：押金、房东卖房、买卖不破租赁
- ★ 婚恋家庭：彩礼、离婚财产、孩子抚养
- ★ 买房买车：定金 vs 订金、房屋买卖
- ★ 消费维权：网购退货、商家欺诈退一赔三
- ★ 宠物：宠物伤人、遛狗责任
- ★ 邻里：漏水、噪音、高空抛物
- ★ 个人信息与人格权：肖像、名誉、个人信息保护

**治安管理处罚法篇（最常见的违法离你最近）**
- ★ 什么是"违法但不犯罪"：拘留/罚款全景
- ★ 打架：殴打他人、结伙斗殴
- ★ 扰序：寻衅滋事、噪音扰民、张贴涂写
- ★ 侵财：小额盗窃、损毁财物、强拿硬要
- ★ 网络违法：网上辱骂、散布谣言
- ★ 新法亮点：违法记录封存、无人机/低空违规等新增条款解读

### 4.4 关键页面规格

**知识卡详情页（核心页面）**
1. 标题（场景化问句）+ 一句话结论徽章（三色：违法 / 可能违法 / 不违法但需注意）
2. 场景故事（300 字内，人物化叙事，改编自官方案例或典型情境）
3. 白话拆解（要点列表，每点可展开法条原文）
4. 法条原文卡片（法律名 + 条号 + 施行版本，可复制）
5. "常见误区"（如"很多人都以为…其实…"）
6. 页脚：来源标注 + 免责声明 + 纠错入口

**法条详情页**
- 条号、官方原文（大字号友好）、施行版本状态
- "人话解读"折叠区（复用关联知识卡的白话拆解）
- 关联知识卡/案例列表（双向链路）

## 5. 非功能需求

| 维度 | 要求 |
|---|---|
